# 🐉 Dragon Slayer — Top-Down Mini Game

A fast-paced **top-down action game** built with **Python (Pygame)** for the **Ural Federal University (UrFU)** project.  
Your mission: **defeat the dragon** and **eliminate all of its doppelgangers** before they overwhelm you!

---

## 🎮 Gameplay Overview

You play as a lone hero in a closed arena where a mighty dragon and its summoned doppelgangers threaten the realm.  
Move swiftly, dodge enemy attacks, and use your weapon to destroy every foe.

**Objective:**  
Kill the **Dragon** — the main boss — and all the **Doppelgangers** it summons.

---

## 🕹️ Controls

| Key | Action |
|-----|---------|
| `Up / Left / Down / Right` | Move up / left / down / right |
| `SPACE` | Attack / Shoot |
| `ESC` | Quit |
| `Z` | Heal |

---

## 🧱 Features

- **Top-down perspective** built with **Pygame**
- **Boss fight** with a unique dragon enemy
- **Dynamic enemy summoning** — the dragon spawns doppelgangers during the battle
- **Smooth player movement** and collision detection
- **Health system** for both player and enemies
- **Particle effects** (optional visual polish)
- **Sound effects & background music**
- Simple **victory / game over screens**

## ⚙️ Installation & Setup

1. **Clone the repository**

    ```bash
    git clone https://github.com/yourusername/Urfu-game.git
    cd Urfu-game
    ```

2. **Virtual Environment**.

    Linux/MacOS

    ```bash
    python3 -m venv venvå
    source ./venv/bin/activate
    ```

    Windows

    ```bash
    python -m venv venv
    .venv/Scripts/activate
    ```

3. **Install all dependencies**

    ```bash
    pip install -r requirements.txt
    ```

4. **Run the game**
    ```bash
    python src/main.py
    ```
